# Smart Table (SP7 API)

https://github.com/AlsuFakhrutdinova/smart-table

> Интерактивная таблица данных с поиском, фильтрацией, сортировкой и пагинацией, работающая через серверное API

## Что изменилось

Таблица была переведена с клиентской обработки статических данных на взаимодействие с сервером.  
Клиентская логика фильтрации, поиска и сортировки заменена формированием `query`‑параметров, которые отправляются в API.  
Функция `render` стала асинхронной, данные запрашиваются с сервера при каждом изменении состояния.

### Основные изменения

- **API‑слой (`data.js`)** – добавлены функции `getIndexes` и `getRecords`, кеширование справочников и запросов, преобразование данных сервера в формат таблицы.
- **Пагинация (`pagination.js`)** – разделена на `applyPagination` (формирование `limit` и `page`) и `updatePagination` (обновление UI после получения данных).
- **Фильтрация (`filtering.js`)** – вместо клиентской фильтрации формирует объект `filter[…]`; добавлена функция `updateIndexes` для асинхронного заполнения селектов.
- **Поиск (`searching.js`)** – вместо локального сравнения добавляет в `query` параметр `search`.
- **Сортировка (`sorting.js`)** – формирует параметр `sort` в формате `field:direction`.

### Архитектура

Компоненты больше не изменяют данные напрямую, а последовательно дополняют объект `query`.  
После формирования всех параметров выполняется асинхронный запрос к серверу, и таблица рендерит полученные `items`.
