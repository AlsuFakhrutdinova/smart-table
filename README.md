# sp6-2_smart-table_starter

> Интерактивная таблица данных с поиском, фильтрацией, сортировкой и пагинацией

## Возможности

Реализован полнофункциональный компонент таблицы с:

- Отображением данных о продажах
- Поиском по всем текстовым полям
- Фильтрацией по колонкам с диапазоном для суммы
- Сортировкой по дате и сумме
- Пагинацией с настройкой количества строк

## Архитектура

Композиция модулей, единый pipeline обработки данных, событийная модель через форму, переиспользуемый компаратор для сравнения.
